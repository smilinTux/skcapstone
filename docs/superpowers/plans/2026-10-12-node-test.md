# Native Node test recipes

Implement the approved root Node recipe without changing Vitest contracts.

1. Detect root package.json and tests/*.test.mjs without apps/web. Validate bounded explicit targets and the bootstrap. Keep baseline exclusions explicit in the recipe.
2. Reuse the qualified Node runtime and immutable dependency artifact, with root package, lock and bootstrap fingerprints.
3. Execute one sandboxed native Node command per target. Native Node 22 JUnit has no filename attribute, so separate reports are required to prove per-file coverage. Seal each target and report filename in the check list.
4. Validate every native report, rejecting missing coverage, failure, cancellation, skip and malformed XML. Exercise profile, sandbox and receipt integration alongside existing Vitest tests.
5. Record the known skgateway metrics baseline exclusion, run focused tests and formatting, push a PR without merging.
