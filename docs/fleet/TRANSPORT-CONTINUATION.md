# Retained GLM transport continuation

A gateway413 is an infrastructure failure, not a producer verdict. The
operator may authorize one fresh native session under the same source claim
after the gateway fault has been repaired. This is an explicit variant of
`skcapstone fleet builder-continue`, not a new offer or a claim transfer.

Use the existing production policy and authority host context. Provide the
exact card, node, request, claim and invocation, `--agent`, `--reason`, and
both `--transport-session` (the Pi session basename) and
`--transport-sha256` (the hash of its unchanged JSONL bytes). The default is
check only. `--apply` preserves the complete workspace and writes a private,
expiring, attributed grant; it does not itself launch a service.

The fixed installed node probe requires positive native terminal proof,
the exact retained claim and source binding, and a session in that owner's
workspace-specific Pi directory. The session must start within 30 seconds
of the trusted native invocation and end before its terminal transition.
Its final provider message must be a gateway413 `request_too_large` with
the configured body limit actually exceeded. No transcript content is
returned to the authority or included in the grant.

The path permits a clean or dirty named branch at the exact offered base.
All source bytes, Git metadata and ignored files are archived and checked
again before consumption. Historical outcomes remain pinned and unchanged;
an outcome from the current claim or any already published source artifact
forbids this continuation. The ordinary retry limit is unchanged.
An exact final ordinary attempt can receive this single continuation, which
is recorded before native launch and cannot be replayed or chained.

Consumption uses the existing worker launcher, current route preflight,
host resource admission, quotas and test-profile checks. No old conversation
is resumed. A lost or changed receipt, claim, source, session, outcome,
policy, process identity or grant withholds execution. Product completion
still requires a new bound candidate and independent review.
