Agent homes no longer fork into Syncthing conflict copies on every fleet restart: per-host runtime state (`memory/wal`, `daemon.pid.identity.json`, `shutdown_state.json`, `trust/trust.json`, `security/audit.log`, `comms/outbox-retry`) is now in the default `.stignore`, and the daemon's graceful-shutdown note goes to its log instead of the synced `journal.md`. New `skcapstone-conflict-guard.timer` (`scripts/sync-conflict-guard.sh`) raises a GTD item when more than 5 new conflict copies appear on a host in a day.
