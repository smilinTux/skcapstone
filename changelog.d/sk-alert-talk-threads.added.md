`sk-alert` groups recurring alerts into Nextcloud Talk threads. The first alert for a de-dup key starts a thread and every later one replies into it, so a condition that fires twenty times reads as one collapsible item instead of twenty near-identical lines (verified server-side: three messages sharing `threadId`, repeats carrying `parent`). The two flags answer different questions and recurring conditions want both, since `-k` alone suppresses the repeat so there is nothing left to group: `-k` with `-t` sends the repeat AND threads it. Thread roots expire after `SKALERT_THREAD_TTL` (7 days) so a condition returning months later starts fresh, and a root that has been deleted in Talk is detected, forgotten and re-rooted rather than failing every reply forever.
