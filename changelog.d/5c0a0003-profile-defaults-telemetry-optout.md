`skcapstone register` and `upgrade` now apply two host profile defaults: third-party telemetry opt-out (HyperFrames: host-local `environment.d` file and `~/.hyperframes/config.json`) and agent skill links via `skskills.agent_links` when the installed skskills provides it. An explicit `telemetryEnabled: true` is respected (nothing written), symlinks are never written through, config.json additions carry a `_skcapstone_telemetry_optout` marker, and `python -m skcapstone.telemetry_optout undo` reverses them. Also fixes onboarding writing two `~/.bashrc` profile blocks on a repeated "update". `SKCAPSTONE_PROFILE_DEFAULTS=0` skips both defaults.
