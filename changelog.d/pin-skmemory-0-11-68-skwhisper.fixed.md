The fleet dependency pins moved to skmemory 0.11.68, which carries the archive-aware prune, so the daily reconcile no longer treats a memory the promoter moved to cold storage as an orphan. skwhisper is now pinned at 0.6.2 as well, which only became possible once that project gained a publish workflow and a PyPI Trusted Publisher; before that the index carried only 0.1.0 while every chi host ran 0.6.2 from git, so any pin would either have failed to resolve or downgraded the fleet. The dependency parity check now reads optional dependencies as well as base ones, because CI and rollout both install the extras under the same constraints file, and reading only base dependencies made it impossible to pin an optional dependency at all.
