`skcapstone doctor` no longer hangs on fleet hosts. The memory drift and sync-timer checks used to walk every agent folder with a `memory/` dir (1,272 on chiap04, almost all ephemeral coding-fleet seats) with one `skmemory health` subprocess each, and for every unregistered seat skmemory reported on the `template` agent instead, so those checks measured the wrong corpus. They now cover the active agent plus the registered memory profiles, run in a small pool under a total time budget (`--drift-budget`, default 120 s), and fail when skmemory resolves an agent to a different one. `--all-agents` adds a read-only, in-process sweep of every other memory folder. New `skcapstone agents stale` reports idle worker seats and their size (dry run; `--archive` moves them, never deletes).
