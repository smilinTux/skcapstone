# SKIP LEDGER -- every test that is allowed to skip must be named here.
#
# THE INVARIANT (CONTRIBUTING.md): a green that can be produced by absence is
# not a green. A skipped test reads as coverage in every summary that matters
# while being structurally unable to fail the build. That is not a hypothetical:
# on 2026-09-19 this suite contained 72 tests that can ONLY skip on a CI runner,
# and one of them (the Pi allowlist probe) has been RED on the only machine that
# can run it, invisibly, because CI never executes it.
#
# Enforcement lives in tests/conftest.py. Any skip whose nodeid does not start
# with one of the prefixes below FAILS the run, and the failure message prints
# the exact line to paste here. Declaring a skip is cheap; a silent one costs a
# gate.
#
# Format: one nodeid PREFIX per line. `#` comments and blank lines ignored.
# Each entry must carry a disposition on the preceding comment line:
#   LOCAL-ONLY  legitimately cannot run on a runner; skip is correct and declared
#   CI-GAP      should run in CI and does not; the dependency needs installing
#   DEAD        cannot run anywhere; needs implementing or deleting
#   MATRIX      skips only on some interpreter/OS in the matrix; correct
