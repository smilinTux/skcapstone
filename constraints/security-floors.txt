# security-floors.txt: minimum versions that clear the known advisories reported
# by the nightly `sksecurity sweep deps` (pip-audit) as of 2026-11-13.
#
# This is a CONSTRAINTS file, not a requirements file: a line here only bounds a
# package when something else already pulls it in, so it is inert for packages a
# given install does not use. Use it on every fleet install and upgrade so that
# transitive dependencies (which no SK pyproject pins) cannot resolve to a
# vulnerable release:
#
#   PIP_CONSTRAINT=<skcapstone>/constraints/security-floors.txt pip install -U ...
#   uv pip install -c <skcapstone>/constraints/security-floors.txt ...
#
# scripts/install.sh exports PIP_CONSTRAINT to this file automatically.
#
# NOT listed on purpose (no fixed release, or the fix conflicts with a pinned
# consumer), tracked as residuals in the CVE remediation report:
#   chromadb      all releases through 1.5.9 are affected, no fixed version exists
#   pillow        13.0.0 clears every advisory but gradio caps pillow<13; floor is
#                 declared directly by skchat instead
#   torch         2.13.0 clears the advisory but torchaudio (s3tokenizer) is built
#                 against torch 2.11; bumped by hand in venvs that do not need it
#   black         dev tool; bumping it reformats code, so it is left to each repo
#
